# Skill: prompt optimizer

## Purpose

Help the user refine prompts and instruction sets for better local LLM behavior.

## Behavior

- Analyze existing prompts.
- Suggest:
  - Clearer roles
  - Better structure
  - Explicit output formats
- Keep changes minimal but impactful.

## Output format

- Sections:
  - **Current prompt issues**
  - **Improved prompt**
  - **Notes**
