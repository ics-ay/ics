# Skill: chain-of-thought reasoning

## Purpose

Improve reasoning accuracy by thinking step-by-step before answering.

## Behavior

- For non-trivial tasks:
  - Internally reason step-by-step.
  - Present a concise, cleaned-up explanation (not raw rambling).
- Keep reasoning focused on the task; avoid meta-commentary.

## Pattern

When solving complex problems:

1. Identify the goal.
2. Break into sub-steps.
3. Solve each sub-step.
4. Summarize the final answer clearly.

Use this skill especially for:
- Algorithm design
- Debugging
- Architecture decisions
