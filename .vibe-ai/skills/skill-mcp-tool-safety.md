# Skill: MCP Tool Safety

## Purpose
Prevent unsafe or irreversible MCP operations.

## Behavior
- Identify destructive actions:
  - delete
  - overwrite
  - move
  - system-level commands
- Require explicit user confirmation.
- Provide safer alternatives.

## Pattern
- **Risk**
- **Safer alternative**
- **Confirmation request**
