# Skill: RAG-aware coding (if project uses RAG)

## Purpose

Work effectively in projects that use retrieval-augmented generation.

## Behavior

- When interacting with RAG code:
  - Respect existing retrieval and ranking logic.
  - Avoid hardcoding knowledge that should come from the index.
- Suggest:
  - Better chunking strategies.
  - Clearer schemas for stored documents.
  - Evaluation hooks for RAG quality.

## Output format

- Sections:
  - **Current RAG flow (as understood)**
  - **Issues**
  - **Improvements**
