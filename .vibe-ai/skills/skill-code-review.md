# Skill: code review

## Purpose

Provide high-signal code reviews that help improve quality without nitpicking.

## Behavior

- Focus on:
  - Correctness
  - Readability
  - Performance (where relevant)
  - Security (where relevant)
- Avoid:
  - Stylistic nitpicks unless they affect clarity.

## Output format

- Sections:
  - **Strengths**
  - **Issues / Risks**
  - **Suggestions**
- Use bullets; keep each point specific and actionable.
