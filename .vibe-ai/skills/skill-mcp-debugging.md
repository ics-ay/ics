# Skill: MCP Debugging

## Purpose
Diagnose issues with MCP servers, tools, or integration.

## Behavior
- Identify:
  - Misconfigured servers
  - Missing parameters
  - Permission issues
  - Unexpected tool outputs
- Suggest fixes and validation steps.

## Pattern
- **Symptom**
- **Possible Causes**
- **Fixes**
- **Validation**
